【1. 作品概要】
本作品「Shizunari.」は、現代のSNSが抱える「数字（いいね・フォロワー数）の競争」や
「承認欲求の過熱」から離れ、自分の本音や内省的な哲学を静かに手放して置いておける
思索型マイクロブログ（Webアプリケーション）です。

日本庭園の「水琴窟」に着想を得ており、Web Audio APIによるプロシージャル環境音合成や、
Google Gemini APIを用いた感情分析・今日の問い・多言語翻訳機能を統合しています。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
審査用PCのローカル環境でソースコードからビルド・起動される場合は、
以下の手順に従ってください。

[動作環境]
- OS: macOS / Windows / Linux
- 実行環境: Node.js 20.x 以上（推奨: v20.x または v22.x）
- 推奨ブラウザ: Google Chrome, Safari, Microsoft Edge

[起動手順]
1. ターミナル（Windowsの場合はコマンドプロンプトまたはPowerShell）を開き、
   本フォルダ（Shizunari_Submission）へ移動します。
   
2. 依存パッケージをインストールします。
   $ npm install

3. 開発サーバーを起動します。
   $ npm run dev
   
   ※本フォルダ内にはあらかじめ動作確認用の環境変数（.env.local）を
     同梱しておりますので、個別にAPIキーを取得・設定いただく必要はございません。

4. ブラウザで以下のURLを開きます。
   http://localhost:3000


【3. 主な審査・体験ポイント】
1. 共感の波紋と水琴窟サウンド（タイムライン / 投稿詳細）
   - 「共感」ボタンをクリックすると、水面に広がる同心円状の波紋演出とともに、
     Web Audio APIでリアルタイム合成された水滴音が鳴ります（数字競争の排除）。

2. ゼノ・アンビエント環境音エンジン（ヘッダー / 設定画面 / 深夜バナー）
   - 外部音声ファイルを一切読み込まず、ブラウザの数学的計算のみで環境音
     （水琴窟、夜の波、竹林の風、焚き火）を低負荷・通信量0MBでプロシージャル合成します。

3. コミュニティの「心の天気」（トップ画面）
   - 投稿テキストをGemini APIが自然言語解析し、全体の感情傾向を「晴れ・雨・曇り・嵐」
     としてリアルタイム集約・可視化します。

4. マイジャーナル（/journal）
   - 過去の自分の思考ログと感情バランス（喜び・疲れ・悲しみ・怒り）を
     カレンダーUIで客観的に内省できます。

5. AIと思索を深める対話機能
   - トップ画面の「今日の問い（Daily Prompt）」
   - 世界20体の文化的・哲学的ペルソナを持つ自律型AIボットとの対話・議論


【4. フォルダ構成】

- scripts/       : ベクターアイコン一括自動生成スクリプト
- .env.local     : 審査確認用APIキー設定（Firebase, Gemini API）
- package.json   : 依存ライブラリ一覧
- README.md      : GitHub向け詳細仕様ドキュメント
- README.txt     : 本ファイル（審査員向けご案内）
